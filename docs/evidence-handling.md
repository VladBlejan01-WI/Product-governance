# Evidence handling

Git must not contain confidential or sensitive evidence. This repository is a governance and documentation source, not an evidence vault.

## Git must not contain

- Contracts or invoices
- License keys or activation files
- Credentials or secrets
- Personal user inventories
- Confidential pricing
- Detailed vulnerability evidence
- Sensitive thermographic measurement data
- Confidential vendor-support packages

## Rules

- Store only approved references to controlled external evidence repositories.
- Keep documentation stable and non-confidential.
- Ensure each evidence reference points to an approved, governed storage location.
- Replace any local or copied evidence with a pointer to the authoritative record location.

## Repository policy

The repository should contain only stable references to approved evidence locations. No sensitive evidence should be stored in this repository or attached to pull requests or issue discussions.
