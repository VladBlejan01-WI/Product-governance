# Governance model

This repository defines the governance baseline for product documentation and portfolio oversight.

## Model principles

- Product records are maintained in Git as the controlled documentation source.
- Backlog work remains in the work-management platform.
- Contracts, invoices, entitlement evidence, confidential security evidence, and personal data remain in a controlled records platform and are referenced only by stable location.
- Governance decisions must be supported by approved evidence and reviewed periodically.

## Product records

Each product entry contains:

- A product metadata record in YAML.
- A product README summarizing the logical product boundary.
- An evidence index containing only approved references.
- Supporting portfolio and governance documentation.

## Review cadence

This repository expects a quarterly governance review cycle unless a product requires a different cadence established by evidence.
