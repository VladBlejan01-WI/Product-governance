# Naming conventions

This repository uses a small set of naming rules to keep the portfolio consistent and scalable.

## Folder names

- Use lowercase kebab-case for all new folders.
- Examples: `irbis3-professional`, `portfolio`, `product-governance`

## Product identifiers

- Use uppercase identifiers with a short product code when available.
- Example: `IRBIS3-PRO`

## Files

- Use descriptive names that match the governance topic.
- Prefer simple, stable names over abbreviations where clarity matters.

## Metadata

- Use YAML for structured metadata records.
- Use Markdown for narrative guidance and governance notes.
