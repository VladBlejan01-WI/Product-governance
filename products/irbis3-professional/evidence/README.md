# Evidence index

This directory intentionally stores only stable references to approved evidence repositories and controlled-record locations.

## Rules

- Do not store contracts, invoices, license keys, activation files, credentials, personal data, or confidential security evidence in Git.
- Use approved external evidence locations and document their reference paths here.
- Replace any placeholder evidence location with the authoritative source only after verification.
