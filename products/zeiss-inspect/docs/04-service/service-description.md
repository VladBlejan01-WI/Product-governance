# Service Description

## Service model

ZEISS INSPECT and Pro are reported as local desktop applications used in metrology and quality workflows. No dedicated application server or database has been identified in intake. ZEISS Quality Suite, license management/dongles, sensor drivers, VMR, measurement hardware/data, PLM, and CAD workflows are candidate dependencies whose local configuration needs confirmation.

## Support

Stakeholder intake reports local experts and ZEISS technical/application support for troubleshooting, licensing, and application guidance. It also reports that there is no centrally documented service process or service catalog entry and no known formal SLA.

## Proposed support path (not yet approved)

1. Local measurement-system user/key user performs approved first-line checks.
2. Local metrology/application expert handles method, sensor, PLM, and CAD workflow triage.
3. Endpoint/software owner handles package, driver, Windows, and version issues.
4. ZEISS support handles vendor-level product/application escalation under verified entitlement.

Named contacts, response times, support hours, service targets, incident route, and escalation records remain TBD. No SLA is asserted.
