# Incident Management

**Document status:** Draft baseline  
**Owner:** TBD  
**Review frequency:** Quarterly or on material change  
**Last reviewed:** 2026-08-24

> Standardize incident handling.

## Severity inputs

Number of affected users, production/test impact, data loss risk, safety/quality impact, workaround, deadline, and contractual consequences.

## Flow

Triage -> contain -> diagnose -> restore/work around -> vendor escalation -> validate -> close -> problem/ADR/update documentation.
