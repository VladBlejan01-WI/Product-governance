# Capabilities

The supplied vendor documentation and research report describe these capabilities for the Bode Analyzer Suite/Bode hardware combination:

- Frequency-response measurements of magnitude and phase across a defined frequency range
- Control-loop analysis and stability-related evaluation with a suitable injection setup
- Impedance, component, and network characterization with suitable fixtures, adapters, and calibration
- Comparison of measurements and trace analysis
- Saving configurations, calibration data, measurement data, and display settings in `.bode3` files
- Loading legacy `.bodex`, `.bodz`, and `.bode` files as documented for BAS 3.00 or newer
- Exporting measurement data to CSV or Excel-compatible files and creating Touchstone files
- Clipboard export of charts, trace data, and settings
- Potential automation/data exchange through SCPI; the supplied BAS 3.52 manual states that its SCPI interface is not a remote control of BAS and that BAS cannot control Bode 100 or Bode 500 at the same time as an SCPI server

Exact availability depends on the installed BAS release, licensed features, hardware, firmware, and configuration. Validate before relying on any capability operationally.
