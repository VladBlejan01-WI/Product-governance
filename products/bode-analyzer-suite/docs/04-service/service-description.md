# Service Description

## Service model

Bode Analyzer Suite is a local engineering/laboratory endpoint application used with compatible Bode hardware. It is not documented as a server or SaaS service in this baseline.

## Proposed support and recovery path

1. User or key user performs initial troubleshooting and checks the known-good setup.
2. Internal endpoint/application support addresses installation, Windows, driver, and package issues.
3. Vendor support handles product-specific escalation.

Recovery should reinstall the approved BAS version, reconnect validated hardware, restore approved templates/scripts/results, and complete a known-good verification measurement.

No 24x7 service requirement or target availability is verified. A validated spare workstation may be justified for schedule-critical laboratories; decision and owner are TBD.
