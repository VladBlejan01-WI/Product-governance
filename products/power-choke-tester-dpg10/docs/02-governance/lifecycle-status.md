# Lifecycle Status

**Current status:** Onboarding baseline; deployment approval and installed state are unverified.

The SharePoint product folder contains a version subfolder named `DPG10_V3.9.4` and setup/demo executable names carrying `3.9.4`. This identifies available staged package material only. It does not establish the installed version, package integrity, vendor support status, or approved deployment.

The supplied main manual documents Windows 10 and Windows 11. Current OS support and support lifecycle must be checked against current vendor evidence before approving a package or upgrade.

## Required lifecycle gates

1. **Identify:** confirm installed software release, tester models/assets, location, users, owners, and business process.
2. **Validate:** verify vendor source, installer signature/hash, supported OS, package components, entitlement, safety setup, and representative measurement.
3. **Integrate:** inventory any API/DLL, LabVIEW, database, InterfaceBox, or production-line configuration actually in use; document interfaces and owners.
4. **Approve:** complete endpoint/security, data, safety, commercial, and operational reviews.
5. **Operate:** manage updates, backups, support, hardware/calibration dependencies, and periodic review.
