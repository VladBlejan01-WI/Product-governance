# Service Description

## Service model

DPG10 is a Windows endpoint engineering/production test application paired with dedicated measurement hardware. The documentation describes Main and Production applications and optional equipment/interfaces. It is not established as a SaaS or enterprise-hosted service.

## Proposed support boundary

- Endpoint/application support: installation, managed workstation, software baseline, and recovery — owner TBD.
- Engineering/production key user: test configuration, representative acceptance, and measurement-method knowledge — owner TBD.
- Hardware/service owner: tester, optional extension/interface hardware, accessories, and calibration — owner TBD.
- Vendor support: product-specific escalation under verified support entitlement — TBD.

## Availability and recovery

No service hours, SLA, recovery target, or business-impact classification is established. Recovery should use an approved software/hardware baseline, restore configuration and measurement data from approved storage, and complete a known-good test according to an authorized procedure. Actual recovery steps and acceptance are TBD.
