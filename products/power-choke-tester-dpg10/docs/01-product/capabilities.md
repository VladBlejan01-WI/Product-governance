# Capabilities

The supplied DPG10 product documentation describes the following product capabilities:

- Measurement and analysis of inductive power components.
- Measurement/calculation of differential inductance, amplitude inductance, flux linkage, magnetic co-energy, DC resistance, and flux density.
- Testing from small SMD inductors through larger power reactors, subject to the selected model and test setup.
- Main and Production PC applications; the manuals state the two-application arrangement is available from software version 3.5.x.
- Data storage/export using XML, SQLite, PDF reports, CSV, and ODBC-connected database options including SQLite, MariaDB, and MySQL, as documented for the product.
- API/DLL-based automation, with examples for .NET and C++; LabVIEW support is also documented.
- Optional three-phase measurement with the Extension Unit. The extension manual states three-phase differential-inductance support is available since software version 3.7.
- Optional InterfaceBox INT1 for production-line integration, with configurable inputs and outputs.

Capability availability depends on the exact tester model, software release, optional hardware, configuration, and entitlement. The local installed configuration has not been verified.
