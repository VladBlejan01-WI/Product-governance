## Product summary

The ed-k Power Choke Tester DPG10 is a dedicated inductive-component test system comprising Windows PC software and DPG measurement hardware. The documented product family includes DPG10 B-Series and DPG20 devices. Software version 3.9.4 is present in the SharePoint package folder name and setup/demo filenames; the installed version at Weidmüller is not verified.

Documented use includes engineering, research, quality control, and production testing of inductive power components. Optional hardware includes the 3-Phase Extension Unit and InterfaceBox INT1 for production-line integration.

## Product boundary
