- License/EULA, entitlement, contract, support coverage, and renewal dates
- Named product/business/technical/service/security/data owners and approved operator groups
- Production-line/API/database integrations in actual use
- Data classification, storage, backup, retention, access controls, and recovery arrangements
- Security, vulnerability, update, and endpoint-policy review
- Safety assessment and authorized operating procedure for the actual test setup
