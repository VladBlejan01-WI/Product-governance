# {{PRODUCT_NAME}} Product Template

This template provides the default structure for onboarding a new product into the portfolio governance repository.

## Purpose

Use this template for product documentation, metadata, governance, architecture, service, compliance, commercial, and delivery guidance. The template is intentionally generalized and should be adapted using authoritative evidence only.

## Required instructions

1. Replace all `{{PLACEHOLDER}}` values with the actual product data.
2. Use `TBD` where facts cannot be validated.
3. Keep the package focused on enterprise product governance and service boundaries.
4. Do not add vendor source code, confidential evidence, or credentials to Git.
5. Update the product catalog and portfolio review records after finalizing the product entry.

## Template sections

- Product metadata: [product.yaml](product.yaml)
- Product documentation: [docs/](docs/)
- Diagrams: [diagrams/](diagrams/)
- Reusable templates: [templates/](templates/)
- Checklists: [checklists/](checklists/)

## Governance reminder

This repository stores documentation, metadata, diagrams, and decision records. Contracts, invoices, license keys, credentials, personal data, and confidential evidence remain in controlled records repositories and are never stored directly here.
