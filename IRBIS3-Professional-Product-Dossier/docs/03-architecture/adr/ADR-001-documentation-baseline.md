# ADR-001: Documentation Baseline

**Document status:** Draft baseline  
**Owner:** TBD  
**Review frequency:** Quarterly or on material change  
**Last reviewed:** 2026-08-24

> Record the documentation approach.

## Status

Accepted for baseline generation.

## Context

The product requires repeatable ownership, architecture, operations, commercial, licensing, and lifecycle documentation.

## Decision

Maintain Git-based Markdown and machine-readable metadata as the source; distribute a controlled PDF summary and separate stakeholder presentation.

## Consequences

Changes should begin in Git; published artifacts need version/date; confidential evidence remains in approved records storage.
