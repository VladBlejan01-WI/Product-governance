# Security Architecture

**Document status:** Draft baseline  
**Owner:** TBD  
**Review frequency:** Quarterly or on material change  
**Last reviewed:** 2026-08-24

> Define security requirements.

## Controls

Managed endpoint; least privilege; approved software source; integrity validation; controlled installation; malware protection; patch/version review; restricted measurement storage; secure vendor-support transfer; remove sensitive data from diagnostic packages.

## Threats

Unauthorized software use; tampered installer; malicious measurement file; local data loss; inappropriate export; vulnerable unsupported runtime; uncontrolled SDK integration.

## Validation

Security team must determine risk rating and mandatory controls based on actual version, environment, and data.
