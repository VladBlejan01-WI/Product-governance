> Create a triage and escalation model.

## Levels

L1: access, catalog, known articles, basic installation checks.

L2: package/configuration, version, compatibility, data path, reproducibility.

L3: vendor defect, license mechanism, product-specific technical investigation.

## Ticket evidence

User, device, version, licensed modules, error text, reproduction steps, sanitized sample if approved, impact, recent changes, logs, and screenshots.
