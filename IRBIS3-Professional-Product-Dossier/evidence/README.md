## Rule

Store contracts, invoices, entitlement proof, security findings, user lists, and sensitive support packages in approved controlled storage. Link them from the dossier using stable references.

## Minimum metadata

Evidence type, title, owner, authoritative location, effective date, review date, confidentiality, and related decision/control.
